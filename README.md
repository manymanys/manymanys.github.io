# ManyManys

The ManyManys research network website, built with Jekyll and hosted on GitHub Pages.

## Local preview

```sh
bundle install
bundle exec jekyll serve --host 127.0.0.1
```

Open http://127.0.0.1:4000/. To build without serving, run `bundle exec jekyll build`.

See [the website guide](docs/redesign-preview.md) for content editing and publishing instructions.

## Wordmark

The SVG and transparent PNG are in `assets/brand/`. The font is Manrope: weight 800 for “ManyManys” and 600 for “The.” The SVG uses outlined lettering and does not require the font to be installed. Manrope’s SIL Open Font License is included alongside the exports.
